# MERCURI-Device-Code
The scripts above are the result of the collaboration of members of the Nano-Biomolecular Precision Lab at UF and several free online resources and tutorials, mostly from Adafruit themselves. Note that it also utilizes pre-existing libraries available from the Arduino hub.

The "merged_and..." file is the main device algorithm from the successful tests and ran on a Nano ESP32.

The "ProjectModel4" is a GAMS file and was developed to find the optimal sample vessel chamber geometry to get the highest raw spectral intensity captured at the spectrometer aperture. Admittedly, the physical model itself is simplified from reality by making some generous assumptions about the system.
